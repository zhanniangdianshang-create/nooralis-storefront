# Nooralis Course Video Assets

Use this folder only for authorized course preview clips, lesson trailers, or student onboarding videos.

Recommended export:

- Format: MP4 / H.264
- Resolution: 1080p or higher
- Aspect ratio: 16:9 or 9:16 depending on placement
- Duration: 15-60 seconds for landing page previews
- Audio: optional, but avoid copyrighted music unless licensed

Only use videos you own, recorded yourself, commissioned, or licensed for commercial reuse.
